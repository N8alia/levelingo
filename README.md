# 🚀 Levelingo

**Levelingo** is a gamified English learning app designed to help you master English tenses through interactive flashcards.

Learn grammar step by step, earn XP, level up, and build confidence in English.

---

## ✨ Features

🎴 **Flashcards practice**
- Random grammar cards
- Verb + tense + marker system
- Fill in the correct sentence

⏳ **English Tenses Training**
Practice the most useful English tenses:

- Present Simple
- Present Continuous
- Past Simple
- Future Simple
- Present Perfect
- Past Continuous
- Present Perfect Continuous

⭐ **Progress System**
- Earn XP for correct answers
- Level up your English skills
- Track your progress

🧠 **Smart Corrections**
The app helps you understand mistakes:

- Verb form corrections
- Spelling mistakes
- Article mistakes (a/an/the)
- Additional words handling

📊 **Statistics**
- See your progress
- Track difficult tenses
- Practice mistakes again

---

## 🎯 Learning Method

Levelingo focuses on active practice:

1. Choose a tense or topic
2. Get a random card
3. Create a sentence
4. Check your answer
5. Learn from corrections
6. Level up

---

## 🛠️ Technologies

Built with:

- HTML
- CSS
- JavaScript

Runs directly in a browser and can be installed as a Progressive Web App (PWA).

---

## 📱 Installation

Open Levelingo in Safari:

1. Tap **Share**
2. Choose **Add to Home Screen**
3. Launch Levelingo like a normal app
